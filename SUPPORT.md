# MeshWeave Support

MeshWeave is a live Starlink globe for **iPhone and iPad**. Free. No account. No in-app purchases.

Canonical support page: [vibealive.us/support.html](https://vibealive.us/support.html).

## Help

- **Globe is empty** — needs a network connection to CelesTrak. If the live feed is blocked, the app falls back to a bundled snapshot.
- **Dish tracking** — join the Starlink Wi‑Fi / LAN so the phone can reach the terminal at `192.168.100.1`. Grant Local Network when iOS asks. Location is optional and only used if the dish does not publish GPS.
- **Pinch / spin** — drag to rotate the globe in place; pinch to zoom. The globe stays centered.
- **Capture** — saves a generated image of the globe to Photos.
